Formula of engagement: How Interactive Web Environments Foster User Creativity

Problem Statement & Topic Summary

Traditional websites prioritize passive consumption which limits users to a single fixed path with little to none visual involvement. This project examines the relationship between web development and user experience design, which addresses the critical gap that remains uncertain how adding responsive features like changes based on the users physical movements such as head, face, or arm gestures can actively influence their personal creaitivty and engagement online.

Draft of Research Question

How do intereactive features in web focused enviroments influence users creativity and engagement?

Definitions & Assumptions

Intereactive Features: Creative coding that tracks body movements, facial gestures, and responds to cursor movement such as hovering that is built in the style.css
Creative Engagement: The shift from a passive viewer to an active participant who explores and influences the artwork on their screen.
Assumption: I assume that providng a flexible website layout rather than a fixed layout can spark users curiosity.

Significance and/or Value of Study

May help explain how interactive web design can foster creative engagement and what design principles software engineers use to encourage it. It provides a needed foundation for designers that proves that the website layout is a crucial component since it can function as a way to improve user engagement rather than just acting as a simple technology tool.

Proposed Method of Inquiry

My planned research method is a Quasi-Experimental Mixed-Methods Design. I will evulate my website by comparing it to various standard limited control layouts vs. a motion responsive experimental design to record both numerical data and personal reflections from my testers.
